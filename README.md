# 作业收集箱 · Homework Dropbox

一个**免账号、盲传式**的作业收集网站。同学打开网页、选文件夹、直接拖文件上传；系统按内置名单自动识别是谁交的，把文件名规范化为「学号 姓名」；管理员在管理页一键核对谁没交、按文件夹打包下载。

技术栈：Python + Flask，单文件应用，自带液态玻璃风格 UI，开箱即用。

## 功能特性

**同学端（上传页）**
- 顶部显示管理员发布的公告（截止提醒、命名要求等）
- 点击 / 拖拽多选文件，拖几个就同时传几个，不限并发
- 每个文件独立进度条 + 总体进度，网络中断自动重试（最多 2 次）
- 上传前校验：文件类型（拦截可执行文件）、一批 ≤ 20 个文件
- 单文件上限（10–5000MB）与同时上传数（1–100）可在管理端「⚙️ 上传设置」随时调整；**服务端不限制文件大小与并发**
- **小文件确认**：≤ 1KB 的文件弹窗提醒「可能没传对」，确认后才传
- **重复提交确认**：该文件夹已有你的文件时弹窗「替换原文件 / 取消」，不会悄悄生成 `(1)` 副本
- 必须选择文件夹才能上传（不提供"未分类"），服务端同步拦截

**管理端（管理页，顶部 TAB 切换）**
- 📋 文件管理：按文件夹筛选、文件列表、单文件下载/删除
- ⬆️ 上传文件：与同学端完全一致的上传页（管理员代传用）
- 文件夹管理：新建 / **重命名**（不影响里面的文件）/ 删除（连同文件）
- 公告栏（顶部 TAB）：编辑发布/更新/撤下，立即生效在同学上传页顶部
- 批量下载：按文件夹打包 ZIP（选"全部文件夹"时保留目录结构）
- 应交名单：导入「姓名 + 学号」配对，支持粘贴各种格式
- 上传设置（顶部 TAB）：
  - 「名单识别」开关——关掉后管理页的核对入口隐藏，同学上传也不再弹重复提交提示
  - 「自动规范化」开关——关掉后上传保持原名，规范文件名入口隐藏（依赖名单识别）
  - 自定义命名模板；调整客户端上传上限
- 作业核对：自动算出应交/已交/未交，列出未交名单、已交明细、无法识别的文件
- 规范文件名：预览「原名 → 标准名」清单，确认后批量执行

**自动规范化（可开关、模板可自定义）**
- 上传后自动识别文件名里的身份（先精确后子串，必须唯一命中）
- 学号一律取名单里的值——同学文件名里学号写错也会被纠正
- 命名格式随意都认：`学号姓名`、`学号 姓名`、`学号+姓名`、`学号_姓名`、`姓名 学号`、`姓名(1)` 等
- 2 字/3 字/4 字（复姓、双姓）姓名无差别处理
- **管理端可整体开关**，也可自定义命名模板（见下方「上传设置」）
- 认不出是谁、命中多个姓名（如小组作业）→ 保持原样并在核对页标出，不猜

**安全设计**
- 盲传原则：上传页没有任何文件列表/下载接口，同学看不到别人的文件
- 管理页全部接口需令牌（`.admin_token`），无令牌/错令牌一律 401
- 同名一律加 `(n)` 序号，**绝不覆盖**已存在文件

## 快速开始

环境要求：Python 3.8+，安装了 `openssl`（用于生成自签名证书）。

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动（首次运行自动生成自签名证书）
python3 upload_server.py
```

启动后：

| 页面 | 地址 |
|---|---|
| 同学上传页 | `https://localhost:8080/` |
| 管理页 | `https://localhost:8080/admin?token=<令牌>` |

- 管理令牌在项目目录的 `.admin_token` 文件里（首次运行自动生成）
- 自签名证书浏览器会提示不安全，点「高级 → 继续访问」即可（内网/测试用）
- 数据都存在本地 `uploads/` 目录，无需数据库

## 使用流程

1. **建文件夹**：管理页 → 「＋ 新建文件夹」，建议每次收作业建一个（如 `10.22 多媒体PPT`）
2. **导入名单**：「📝 编辑名单」粘贴全班「姓名 学号」（一次性，之后可随时改）
3. **同学上传**：把上传页地址发给同学，他们选文件夹传文件即可
4. **核对**：选好文件夹 → 「🔍 开始核对」→ 看未交名单，直接@没交的人
5. **下载**：「打包下载 ZIP」按文件夹一键打包

## 上传设置（命名模板）

管理页顶部 TAB 切到「⚙️ 设置」：

- **总开关**：关掉后上传文件保持原样（同名仍自动加 `(1)` 防覆盖），查重弹窗和自动改名停用；「作业核对」不受影响
- **客户端上限**：单文件 MB 数（10–5000）与同时上传个数（1–100）；一批仍限 20 个文件
- **命名模板**：用 `姓名` / `学号` / `文件名称` / `日期` 四个关键字自由拼装，中间加任意连接符号，带实时预览：

| 模板输入 | 渲染结果（张三 / 学号17 / 文件example） |
|---|---|
| `学号 姓名`（默认） | `17 张三` |
| `姓名_学号 文件名称` | `张三_17 example` |
| `学号-姓名-文件名称` | `17-张三-example` |
| `姓名-日期` | `张三-2026.10.22` |

说明：`文件名称` 取原文件名（不含扩展名，扩展名自动拼回）；`日期` 为当天，格式「年.月.日」。模板非法（无关键字 / 含 `\/:*?"<>|`）会被拒绝并保留原模板。

## 配置与数据文件

| 文件 | 说明 |
|---|---|
| `.admin_token` | 管理令牌，首次运行自动生成 |
| `.roster` | 应交名单，格式 `姓名\t学号`（学号可省略） |
| `.upload_config` | 上传配置：`{"normalize": true, "template": "学号 姓名"}` |
| `.announcement` | 公告内容（`{"text": "...", "time": "..."}`），无文件=无公告 |
| `uploads/` | 文件存储目录，子目录即文件夹 |
| `cert.pem` / `key.pem` | 自签名证书，首次运行自动生成 |

**固定行为**（无需配置）：同名加 `(n)` 不覆盖；认不出身份的同名文件不弹窗走 `(n)` 保底，防止不同同学同名文件互相覆盖。

## 部署提示

- 这是单机内网使用的设计，**部署到公网请自行评估风险**（建议加反向代理、速率限制、独立域名 + 正式证书）
- 多进程/生产部署可换 gunicorn 等 WSGI 服务器（代码本身兼容）
- 想开机自启：systemd / launchd / supervisor 均可，守护 `python3 upload_server.py` 即可
